# نشر ملتقى ماهر على Vercel — خطوة بخطوة (بلا بطاقة، والبيانات محفوظة دائمًا)

## المحتوى
- `index.html` + `style.css` + `script.js` + `assets/` — **الاستمارة** (الصفحة الرئيسية)
- `admin.html` — **لوحة التحكم** (تُفتح على `/admin.html`)
- `api/register.js` — استقبال التسجيل وتخزينه
- `api/registrations.js` — قراءة المسجّلين (فلتر ذكور/إناث + برنامج)
- `package.json` — يعتمد على قاعدة بيانات Vercel Postgres

بعد النشر:
- الاستمارة: `https://<اسم-مشروعك>.vercel.app/`
- لوحة التحكم: `https://<اسم-مشروعك>.vercel.app/admin.html`
- كود دخول اللوحة: **maher14*2-=sd**

---

## الخطوة 1 — رفع هذا المجلد إلى GitHub (repo جديد أنظف)
لتفادي الخلط مع الملفات القديمة، الأفضل **repository جديد**:
1. أنشئ repo جديدًا في GitHub، مثلاً `maher-vercel`.
2. **Add file → Upload files** وارفع **كل ما داخل مجلد `deploy-vercel`** (الملفات + مجلدات `api` و`assets`).
3. **Commit changes**.

> يمكن أيضًا الرفع داخل نفس repo `cabinetdentaire`، لكن repo جديد أوضح.

---

## الخطوة 2 — إنشاء المشروع على Vercel
1. ادخل <https://vercel.com> وسجّل الدخول بـ**GitHub** (مجاني، بلا بطاقة).
2. **Add New… → Project**.
3. اختر الـrepo الذي رفعته → **Import**.
4. اترك الإعدادات كما هي واضغط **Deploy**. انتظر حتى ينتهي.

---

## الخطوة 3 — إضافة قاعدة البيانات (Postgres مجانية) ⭐
هذه الخطوة هي التي تجعل التسجيلات **محفوظة دائمًا**:
1. من صفحة مشروعك في Vercel افتح تبويب **Storage**.
2. **Create Database** → اختر **Postgres** (أو **Neon**) → **Continue**.
3. اختر الخطة المجانية (Free) → **Create**، ثم **Connect** بالمشروع.
   - Vercel سيضيف إعدادات الاتصال تلقائيًا (لا تحتاج نسخ أي شيء).
4. بعد الربط، اذهب إلى **Deployments** واضغط **Redeploy** لآخر نسخة (حتى تلتقط إعدادات القاعدة).

---

## الخطوة 4 — إضافة كود الدخول (اختياري لكن مستحسن)
1. **Settings → Environment Variables**.
2. أضِف: **Key** = `ADMIN_KEY` ، **Value** = `maher14*2-=sd` → **Save**.
3. **Redeploy** مرة أخرى.

> إن لم تُضِفه، يعمل كود الدخول الافتراضي `maher14*2-=sd` أصلًا.

---

## الخطوة 5 — التجربة
- افتح الرابط الأساسي → املأ الاستمارة وأرسِل → يجب أن تظهر شاشة النجاح.
- افتح `/admin.html` → أدخل `maher14*2-=sd` → يظهر تسجيلك، مع فلتر **ذكور / إناث** وتصدير Excel.

---

## عند أي خطأ
من Vercel: **Deployments → آخر نشر → Logs** (أو **Functions**). انسخ الرسالة وأرسلها لي وسأحلّها معك.
